## 部署前置条件

1. 本机可直接使用 `localhost:8080` 或 `127.0.0.1:8080`；局域网访问再用 `GWASM_ORIGIN` 传入额外的完整 Origin。
2. 防火墙只允许预期设备；公网入口必须另有认证网关，但项目仍不支持共享多用户实例。
3. 允许出站 DNS、HTTPS 与 TCP 6112/80/443 到许可的 ArenaNet/Guild Wars 服务。
4. 按需模式至少预留 1 GB；完整快照约 4.2 GB，运维上预留 5 GB 及 inode/备份余量。
5. TLS 终止必须保持 `Host`/Origin 一致并支持 WebSocket Upgrade 和 Range。

<Aside type="danger" title="反向代理不是安全模型">
它可以终止 TLS、限制源地址和增加外部认证，但 Python relay 仍是面向单个信任域的受限 open proxy。不要把一个实例提供给互不信任的用户。
</Aside>

## 数据位置

Release 默认在 `gwasm.py` 相邻写 `dist/`、`gwpatch-cache/`。容器固定使用 `/data/dist` 与 `/data/cache`；文档永远位于只读 `/app/docs-dist`，不得复制到 `/data`，否则升级镜像后旧卷会遮蔽新文档。
