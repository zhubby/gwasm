## 发行制品

release zip 包含 Python 运行时、`gwasm_core/`、浏览器 harness、图片、字体、精简 README、GPL-3.0 LICENSE 与构建后的 `docs-dist/`。GHCR runtime 镜像包含同等运行内容，但不包含 Node/npm、Astro 源码依赖、测试或工具。

以下内容绝不属于发行制品：APK、Guild Wars 客户端 Wasm、官方 JS glue、4.2 GB snapshot、manifest、chunk cache、用户数据、密码、token 或提取的 key。它们由用户运行时从许可来源获取或在本地派生。`docs-dist/pagefind/` 中只保留文档搜索所需的 Pagefind Wasm，不是游戏二进制。
