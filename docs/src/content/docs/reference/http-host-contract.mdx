## HTTP 端点

| 路径 | 方法 | 响应与约束 |
| --- | --- | --- |
| `/`、静态文件 | GET/HEAD | harness 与客户端；支持单段 Range，游戏 CSP |
| `/docs` | GET/HEAD | `308` 永久重定向到 `/docs/` |
| `/docs/*` | GET/HEAD | 只读 `docs-dist/`；独立 CSP；不存在即 404 |
| `/progress.json` | GET | 更新、下载与预热状态；`no-store` |
| `/ping?id=…[&bye=1]` | GET/POST | `204`；更新 watchdog 标签页身份 |
| `/dns?name=…` | GET | allowlist 域名的 IPv4 文本；403/502 显式失败 |
| `/Gw.snapshot` | GET + Range | 从 ChunkStore 拼接；无 Range 时 416，缺块时 503 |
| `/?dest=IP:PORT` | WebSocket | 同源 TCP relay；Origin/地址/端口检查 |
| `/{route}/…` | HTTP verbs | 已知 route 的 HTTPS proxy；未知 route 502 |

文档命名空间在 proxy 之前终止：任何 `/docs/...` 都只能命中静态文档、重定向或 404。普通与 percent-encoded `..`、反斜杠和目录逃逸不能到达 `docs_root` 外。

## 缓存与响应头

`/docs/_astro/*` 使用 `public, max-age=31536000, immutable`；文件名含内容 hash。HTML、Pagefind index/WASM 和其他文档资源使用 `no-cache`，允许浏览器保留但每次重新验证。所有响应 `nosniff`、`no-referrer`。Pagefind 的 `wasm.*.pagefind` 载荷使用 `application/wasm`。

<Aside type="note" title="HEAD 与 Range">
HEAD 必须返回与 GET 相同的 status/headers 且无 body。静态文档资源支持单段 Range，便于测试和代理兼容；多段 Range 不支持。
</Aside>
