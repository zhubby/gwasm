## Prerequisites

1. Local access works at `localhost:8080` or `127.0.0.1:8080`; set `GWASM_ORIGIN` only for an additional complete LAN Origin.
2. Restrict the firewall to intended devices. A public edge requires separate authentication, but shared multi-user operation remains unsupported.
3. Permit outbound DNS, HTTPS, and TCP 6112/80/443 to allowed ArenaNet/Guild Wars services.
4. Keep at least 1 GB for demand mode. A complete snapshot is about 4.2 GB; reserve 5 GB plus backup and inode headroom.
5. TLS termination must preserve Host/Origin expectations and support WebSocket Upgrade and Range.

<Aside type="danger" title="A reverse proxy is not the security model">
It can terminate TLS, restrict source addresses, and add perimeter authentication. The Python relay remains a constrained open proxy for one trust domain. Do not share an instance between mutually untrusted users.
</Aside>

## Data locations

A release writes `dist/` and `gwpatch-cache/` beside `gwasm.py` by default. Containers use `/data/dist` and `/data/cache`. Documentation always stays in read-only `/app/docs-dist`; putting it in `/data` would let an old volume mask docs from a new image.
